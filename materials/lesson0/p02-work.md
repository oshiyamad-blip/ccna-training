# LESSON0 P2 実習：数の基礎（2進数・16進数・単位）

> 配置先: ドキュメント `02_実習手順書 > LESSON0 > P2`
> 所要時間の目安: 3 時間 ／ 使用ツール: Windows 電卓アプリ（プログラマーモード）、計算ドリル（2進数・16進数の変換）

この実習では、講義で学んだ2進数・16進数の変換を、手計算とPCの電卓の両方で練習します。
手で解いた答えを、電卓で必ず検算してください。
検算までがワンセットの練習です。

## ゴール

- 計算ドリル（2進数・16進数）の初級20問を、手計算で解けるようになる。
- Windowsの電卓アプリ（プログラマーモード）で、2進数・10進数・16進数を相互に変換できる。
- 自分の手計算と電卓の結果を照合し、間違いを自分で見つけて直せる。

## 準備するもの

- 計算ドリル（2進数・16進数）
  - ドキュメント `07_試験対策 ＞ 計算ドリル` を開き、その中の
    「計算ドリル: 2進数・16進数の変換」を選んでください。
    リポジトリでは `materials/drills/binary-drill.md` にあります。
  - 画面で開いたままでも、印刷したものでも構いません。
- 答えを書くためのノート（またはレポート用紙）
- 筆記用具（鉛筆と赤ペン）
- Windows PC（電卓アプリが使えること）

> 計算ドリルの冒頭には「電卓・PC の計算機能は使わず、手計算で解いてください」と
> 書かれています。これは、本編が始まってからの毎日の反復練習についての約束です。
> この P2 では、まず手計算で解いたうえで、答え合わせの道具として電卓を使います。

## 手順

### ステップ1：重み表を書き写す

1. 計算ドリルの「おさらい: 位の重みと変換手順」にある重み表を開きます。
2. ノートの一番上の行に、位の重み「128 64 32 16 8 4 2 1」を自分の手で書き写します。
3. この重み表は、以後すべての問題で使います。書き写せたら次に進みます。

### ステップ2：重み表を暗記する

1. 書き写した重み表を手やノートで隠します。
2. 128から1まで（128, 64, 32, 16, 8, 4, 2, 1）を声に出して3回唱えます。
3. 続けて1から128まで（1, 2, 4, 8, 16, 32, 64, 128）を声に出して3回唱えます。
4. 何も見ずに、重み表を紙へ3回書きます。3回とも正しく書けるまで繰り返します。

### ステップ3：2進数→10進数（前半5問）を解く

1. 計算ドリルの初級から、2進数を10進数に直す問題の前半、**Q1・Q3・Q5・Q7・Q9** を
   ノートに書き写します。
2. 各問題で、2進数の桁の真下に鉛筆で重みを書き込みます。
3. 桁が「1」になっているところの重みだけに丸を付けます。
4. 丸を付けた重みだけを合計し、答えとしてノートに書きます。

### ステップ4：2進数→10進数（後半5問）を解く

1. 同じく初級から、**Q11・Q13・Q15・Q17・Q19** をノートに書き写します。
2. ステップ3と同じ手順（重みを書く→1の桁だけ丸を付ける→合計する）で解きます。

### ステップ5：Windowsの電卓アプリを起動する

1. 画面下部のスタートボタンをクリックすると、画面下部に検索ボックスが表示されます。
2. その検索ボックスに「電卓」と入力します。
3. 検索結果に表示された「電卓」アプリをクリック、またはEnterキーを押します。

**📷ここでスクショ**: 電卓アプリが起動した画面を撮影してください。

### ステップ6：プログラマーモードに切り替える

1. 電卓アプリ左上にある三本線のメニュー（≡）を1回クリックします。
2. 表示された一覧から「プログラマー」をクリックして選びます。

**📷ここでスクショ**: プログラマーモードに切り替わった画面を撮影してください。

### ステップ7：電卓で検算する（2進数→10進数）

1. 画面左側の「DEC」（10進）ボタンをクリックして選択します。
2. ステップ3・4で解いた10問について、自分が手計算で求めた10進数の答えを1問ずつ
   入力してください。
   - 時間が足りない場合は、最低でもQ1・Q5・Q9・Q13・Q19の5問は必ず検算してください。
3. すると画面の「BIN」の行に、自動で2進数が表示されます。
4. この2進数が、ドリルのその問題に書かれていた2進数と一致するか確認します。
   - 電卓は先頭の0を表示しません。たとえばQ1の `01011010` は、電卓では
     `1011010` と7桁で表示されます。先頭の0の有無は違いとして数えず、
     残りの並びが同じであれば一致とみなしてください。
5. 一致していれば、手計算で出した10進数の答えは正解です。
6. 一致しない場合は、重みの書き忘れや足し算ミスがないか、ステップ3・4の計算を見直します。

**📷ここでスクショ**: DECに数値を入力し、BIN欄に2進数が表示された画面を撮影してください。

### ステップ8：10進数→2進数（買い物の考え方）を解く

1. 計算ドリルの初級から、10進数を2進数に直す問題の前半、**Q2・Q4・Q6・Q8・Q10** を
   ノートに書き写します。
2. 講義で学んだ買い物の考え方で、重みの大きい方（128）から順に「今の残額で買えるか
   （引けるか）」を試します。
3. 買えたらその桁に1を書き、代金を残額から引きます。買えなければ0を書き、次の重みに進みます。
4. すべての桁を埋め、8桁の2進数を完成させます。

### ステップ9：Q2〜Q10を電卓で検算する

1. ステップ7と同じ手順で、電卓の「DEC」に問題の10進数を入力します。
2. 表示された「BIN」の値と、自分が手で出した2進数を1問ずつ見比べます。
   - ここでも、電卓側に先頭の0は表示されません。
3. 間違っている問題があれば、赤ペンで正しい答えに直します。

### ステップ10：仕上げ問題を解く

1. 計算ドリルの初級の残り、**Q12・Q14・Q16・Q18・Q20** を、まずは手計算だけで解きます。
2. 初級20問すべて解き終えたら、最後にまとめて電卓で検算します。
3. 検算が終わったら、計算ドリル末尾の「初級 解答（Q1〜Q20）」で最終的な答え合わせをします。

### ステップ11：16進数を電卓で体感する

1. 電卓が「DEC」（10進）の入力になっていることを確認します。
2. 「15」と入力し、画面の「HEX」の行に「F」と表示されることを確認します。
3. 続けて「255」と入力し、「HEX」の行に「FF」と表示されることを確認します。
4. 最後に「HEX」ボタンをクリックし、入力モードが16進数に切り替わって
   A〜Fのボタンが押せるようになることを確認します。

**📷ここでスクショ**: DECに255を入力し、HEX欄にFFと表示された画面を撮影してください。

### ステップ12：重み表の口頭クイズ（1人で音読しながら確認）

1. 重み表「128 64 32 16 8 4 2 1」を見ずに、上から順に声に出して言えるか試します。
2. 「64の隣は？」「16はどこ？」と自分に問いかけ、答えを紙に書いてから重み表で答え合わせします。
3. すらすら言えるようになるまで5分間続けます。

### ステップ13：単位のまとめを書く

1. ノートに「1Byte＝何bit」「1KB≒何B」「B・KB・MB・GB・TBの並び」の3項目を、
   講義の内容を思い出しながら書きます。
2. 続けて、計算ドリルの上級から **Q41・Q42・Q43・Q44** の4問を解きます。
3. 計算ドリル末尾の「上級 解答（Q41〜Q60）」で答え合わせをします。

### ステップ14：誤答ノートに記録する

1. ステップ7・ステップ9・ステップ10・ステップ13で間違えた問題の番号を、誤答ノートに書き写します。
2. それぞれについて、「なぜ間違えたか」（重みの書き忘れ、引き算ミスなど）を一言メモします。

**📷ここでスクショ**: 解き終えたノート全体、または誤答ノートのメモを撮影してください。
紙のノートの場合は、スマホなどで撮った写真で構いません。

## うまくいかないとき

- **計算ドリルがどこにあるか分からない**：ドキュメントの `07_試験対策 ＞ 計算ドリル` を開き、その中の「計算ドリル: 2進数・16進数の変換」を選んでください。リポジトリでは `materials/drills/binary-drill.md` です。この実習で使うのは、初級（Q1〜Q20）と上級のQ41〜Q44だけです。
- **電卓アプリが見当たらない**：スタートボタンから「電卓」と入力しても出てこない場合は、Windowsの設定からアプリの検索を行ってください。個人PCの設定によって表示名が異なることがあります。
- **プログラマーモードのボタン（DEC/BIN/HEX）が見当たらない**：ウィンドウが小さいとボタンが隠れることがあります。電卓のウィンドウを広げてみてください。
- **手計算と電卓の答えが合わない**：まず重み表（128 64 32 16 8 4 2 1）を書き忘れていないか確認します。次に、1になっている桁だけを合計しているか、0の桁を足していないかを確認します。
- **買い物の考え方でどこから手をつければいいか分からない**：必ず128（一番大きい重み）から順番に試します。途中を飛ばすと合わなくなるので、順番を守ってください。
- **時間内に20問終わらない**：ステップ3・4・8（Q1〜Q19の奇数番号と、Q2〜Q10の偶数番号の計15問）までを優先して確実に仕上げてください。ステップ10の仕上げ問題（Q12・Q14・Q16・Q18・Q20）は後で解いても構いませんが、次の小テストに進む前に解き切ってください。

30 分試して解決しない場合は、状況（スクリーンショット + 試したこと）を課題の
コメントに書いて質問してください。わからないことは恥ずかしいことではありません。
質問した人から伸びます。
