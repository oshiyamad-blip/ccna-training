# ラボ開始用 .pkt ファイル 作成作業手順書

`.pkt` ファイルを実際に作る人が、手元に開いたまま上から順に進めるための手順書です。

> **この文書の位置づけ**
>
> | 文書 | 役割 |
> |---|---|
> | `materials/pkt-build-spec.md` | **仕様** — 何を、どこまで作り込むか（レベル A/B/C の定義） |
> | `materials/pkt-build-sheets/exerciseNN.md` | **設計図** — 1 ファイルごとの機器・結線・IP・貼り付けコンフィグ・検収項目 |
> | **この文書** | **作業手順** — Packet Tracer をどう操作して、どの順に、何個作るか |
>
> Packet Tracer の入手・インストール・画面の見方は、受講者向けの
> `03-packet-tracer-manual.md`（1〜2 章）と共通です。未導入ならそちらを先に。

---

## 0. 最初に知っておくこと

### 作るのは 3 つの Exercise だけです

**2026-08 の方針変更で、開始ファイルは原則作らないことになりました。**
受講者は毎回、機器の配置と結線から自分で組みます。Packet Tracer の操作自体が
反復すべき技能だからです。

例外は、ラボの所要時間が枠（150 分）に収まらない次の 3 回だけです。

| Exercise | 内容 | 理由 |
|---|---|---|
| **Exercise10** | 無線 LAN（WLC / LAP） | 有線側は Exercise6〜8 の既習。無線の本題に時間を使う |
| **Exercise17** | ACL | 手順合計 155 分で枠超過 |
| **Exercise20** | 総合演習 | 手順合計 170 分。機器・結線とも最多 |

### 作るファイル

| 種類 | ファイル名 | 用途 | 渡す相手 |
|---|---|---|---|
| **開始ファイル** | `exerciseNN_start.pkt` | 受講者がラボを始める状態 | 受講者（課題に添付） |
| **完成見本** | `exerciseNN_answer.pkt` | 質問対応・採点時の答え合わせ | 講師のみ（`04_講師用`） |

開始ファイルは上記 3 個。完成見本は、質問が出やすい回を中心に必要に応じて
作ってください（**Exercise20 の完成見本は必ず**用意することを勧めます。
総合演習は詰まる受講者が最も多く、口頭で説明しきれません）。

### 所要時間の目安

| ファイル | 目安 |
|---|---|
| Exercise10 start + answer | 40〜50 分（WLC の GUI 設定があるため） |
| Exercise17 start + answer | 30〜40 分 |
| Exercise20 start + answer | **90〜120 分**（別格。機器・結線とも最多） |

**合計おおむね 3〜4 時間**です。以前の見積り（41 個・10〜12 時間）は、
開始ファイルを全 Exercise 分作る前提のものでした。

### 受講者が作る `.pkt` と混同しないこと

受講者は各ラボの成果物を `exerciseNN_氏名.pkt`（例: `exercise04_yamada.pkt`）として
保存し、Backlog の課題に添付して提出します。**これは受講者が作るもの**で、
この手順書の対象ではありません。

## 1. 準備（初回のみ）

1. Packet Tracer を導入する → `03-packet-tracer-manual.md` の 1 章
   （NetAcad の無料アカウントが必要。バージョンは 9.x を前提）
2. 作業用フォルダを 2 つ作る

   ```
   pkt/start/    … exerciseNN_start.pkt を置く（受講者に配る）
   pkt/answer/   … exerciseNN_answer.pkt を置く（講師のみ）
   ```

   **最初からフォルダを分けてください。** 完成見本を誤って受講者に配ると、
   ラボが答え合わせになってしまいます。
3. Packet Tracer の設定を 1 つ変えておく
   （Options > Preferences > Interface）
   - **「Show Link Lights」を ON** — リンクの色（橙/緑）が見えないと検収できません

## 2. 1 ファイルの標準手順

**Exercise06 を例に説明しますが、どのファイルも手順は同じです。**
作業中は `materials/pkt-build-sheets/exercise06.md` を横に開いておきます。

### 手順 1: ビルドシートの冒頭 3 行を読む

- **作り込みレベル**（A / B / C）— 受講者に何を残すかが決まります
- **保存ファイル名**
- **対象ラボ** — 迷ったときの最終的な正はこちら

### 手順 2: 機器を置く（「1. 機器リスト」）

左下のデバイスボックスから、シート指定の**モデル番号どおり**に選びます。

- ルータ: 既定では ISR 4331 が出ることがあります。シートが **2911** と書いていれば
  必ず 2911 を選んでください（インターフェース名が `Gi0/0` と `Gi0/0/0` で変わり、
  手順書のコマンドが通らなくなります）
- 置いたら**すぐ名前を変える**（機器をクリック → Config タブ → Display Name）。
  シートの「配置名」列と一致させます。後回しにすると結線時に取り違えます

### 手順 3: 結線する（「2. 結線表」）

稲妻アイコン →「自動選択」で、シートの表の上から順につなぎます。

- **ポート番号は表のとおりに**。`Fa0/1` と `Fa0/2` を入れ替えると、後で
  受講者の手順書と食い違います
- リンクが**赤**のままなら、自動選択をやめて表指定の種別（ストレート/クロス）で
  つなぎ直す
- スイッチが絡む結線は、つないだ直後は**橙**です。STP の収束に約 30 秒かかります

### 手順 4: PC・サーバを設定する（「3. PC/サーバ設定」）

機器をクリック → Desktop タブ → IP Configuration に、表の値を入れます。

> **レベル B のときは入れません。** シートに「開始ファイルでは未設定のまま」と
> 書かれていたら、そのとおり空欄で保存します（IP 設計がその日の学習対象のため）。

### 手順 5: コンフィグを貼り付ける（「4. 貼り付け用コンフィグ」）

シートに「事前設定なし」と書かれていれば、この手順は飛ばします。

貼り付け方:

1. 機器をクリック → **CLI タブ**
2. `Press RETURN to get started.` が出るまで待つ（起動途中だと入力が消えます）
3. Enter → `Router>` が出たら `enable` → `configure terminal`
4. シートのコンフィグ**ブロックをまるごとコピーして、CLI に貼り付け**
5. `end` → `copy running-config startup-config`（Enter で確定）

> **うまく入らないときは 1 行ずつ**貼ってください。まとめて貼ると、機器の
> 起動が終わっていない場合に先頭の数行が捨てられることがあります。

### 手順 6: リンクが全部緑になるまで待つ

橙が残ったまま保存すると、受講者が開いたときに「なぜか繋がらない」状態から
始まります。**全リンク緑**を目視で確認してください。

### 手順 7: 検収する（「6. 組み立て後チェック」）

シート末尾のチェックリストを上から順に潰します。**ここを飛ばさないでください。**
特に次の 1 項目は、飛ばすと受講者が詰まります。

- [ ] **その日の学習対象が「未設定のまま」残っているか**

作り込みすぎ（＝答えが入っている）と、ラボが「Enter を押すだけ」になります。

### 手順 8: 保存する（開始 → 完成見本の順）

1. `File > Save As` → `pkt/start/exercise06_start.pkt`
2. **そのまま続けて**、ラボ手順書（`materials/lesson2/exercise06-lab.md`）の
   手順どおりに設定を入れていく。シートに「5. 完成コンフィグ」があれば、
   それを貼り付けるだけで済みます
3. 動作確認（ping が通る、など。シートの確認用コマンド参照）
4. `File > Save As` → `pkt/answer/exercise06_answer.pkt`

> **順番を逆にしないでください。** 完成見本から設定を消して開始ファイルを作ると、
> 消し残しが必ず出ます。「素の状態を保存 → 足していく」が鉄則です。

### 手順 9: 最後に受講者の目で開き直す

保存した `_start.pkt` を**閉じて、開き直します**。

- 配線・IP が保たれているか
- その日の本題が未設定のままか

ここまでで 1 ファイル完了です。

## 3. 作るときの注意

**① Exercise20 には流用元がありません**

Exercise20（2911×3 + 2960×2 + PC×4 + Server×1）は Exercise14 と機器構成が
1 台違いですが、Exercise14 の開始ファイルは作らないので流用できません。
一から組むことになります。時間を確保してください。

**② 機器名は置いた直後に変える**

後でまとめて直そうとすると、結線時に必ず取り違えます。

**③ コンフィグは 1 機器分をまとめて貼る**

ビルドシートの「貼り付け用コンフィグ」は機器ごとにブロックが分かれています。
1 ブロックずつ貼れば、打ち間違いはゼロにできます。

**④ 作り込みすぎない**

3 つとも「その日の本題」は必ず未設定で残します。作り込みすぎると、
ラボが Enter を押すだけの作業になります。迷ったら**作り込まない側**に倒してください。

## 4. よくある詰まり

| 症状 | 原因と対処 |
|---|---|
| リンクが赤いまま | ケーブル種別の自動選択が外れている。結線表の指定どおり（ストレート/クロス）につなぎ直す |
| リンクが橙のまま緑にならない | STP の収束待ち。30 秒ほど待つ。1 分待っても橙ならポートが shutdown されていないか確認 |
| CLI に貼ったコマンドの先頭が消える | 機器の起動が終わる前に貼っている。`Press RETURN to get started.` を待ってから貼る。または 1 行ずつ |
| `interface GigabitEthernet0/2` が受け付けられない | 機種違い。2911 は `Gi0/0`〜`Gi0/2`、1941 は `Gi0/0`〜`Gi0/1`、4331 は `Gi0/0/0`〜`Gi0/0/2`。`show ip interface brief` で実在する名前を確認 |
| 保存して開き直すと設定が消えている | `copy running-config startup-config` を実行していない。または保存前に機器を再起動した |
| どこまで作り込むか判断に迷う | ビルドシートの「作り込みレベル」に戻る。それでも迷ったら**作り込みすぎない側**に倒す（受講者が手を動かす量が減るほうが害が大きい） |
| ビルドシートとラボ手順書が食い違う | **ラボ手順書が正**（`pkt-build-spec.md` の前提）。食い違いを見つけたら記録して共有してください。シート側を直します |

## 6. できあがったファイルの配り方

| ファイル | 置き場所 | 方法 |
|---|---|---|
| `exerciseNN_start.pkt` | 各ラボ課題 | Backlog の該当課題に**添付**する（`[ExerciseNN] ラボ: …`） |
| `exerciseNN_answer.pkt` | `04_講師用` | 受講者から見えない場所に置く。**課題には添付しない** |

`upload-wiki.mjs` は Markdown 教材専用です。`.pkt` の配布は手動添付、または
共有ストレージ経由になります。

受講者が提出する完成ファイルの名前は `exerciseNN_氏名.pkt`（例: `exercise04_yamada.pkt`）、
LESSON0 の P5 だけ `lesson0-p5_氏名.pkt` です。
