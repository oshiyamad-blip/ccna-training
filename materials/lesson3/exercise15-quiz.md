## 解答・解説（次の Exercise の開始時に公開・講師用）

| 問 | 解答 | 解説 |
|---|---|---|
| Q1 | A | 先頭ゼロを省略し、連続する 0 ブロックを `::` で 1 回だけ圧縮すると `2001:db8::1` になる |
| Q2 | B | `::` はアドレス中に 1 回しか使用できない。2 回使うと復元位置が一意に決まらず無効になる |
| Q3 | C | GUA は `2000::/3`（先頭が `2` または `3`）の範囲。A は LLA、B は ULA、D はマルチキャスト |
| Q4 | D | `fe80::/10` はリンクローカルアドレスの範囲で、IPv6 有効なインターフェースに必ず自動生成される |
| Q5 | B | ステートレス DHCPv6 はアドレス自体を SLAAC で取得し、DNS サーバなどの補足情報だけを DHCPv6 サーバから取得する方式。すべてを DHCPv6 サーバから取得するのはステートフル DHCPv6（A） |
| Q6 | A | NDP（近隣探索プロトコル）は ICMPv6 を使い、Neighbor Solicitation/Advertisement によるアドレス解決や DAD を行う、IPv4 の ARP（D）に相当するプロトコル |
| Q7 | C | MAC を前半/後半に分割し中央に `fffe` を挿入、先頭バイト `00` の U/L ビットを反転させると `02` になり `0211:22ff:fe33:4455` となる |
| Q8 | C | `ipv6 unicast-routing` を入力しない限り、ルータは IPv6 ホストとして動作するのみで異なるセグメント間のパケットを中継しない |
| Q9 | A | リンクローカルアドレスはリンクごとのスコープしか持たず、複数のリンクで同じアドレスが重複して存在しうる。そのため出力インターフェースを併記して「どのリンク上の `fe80::2` か」を一意に示す必要がある |
| Q10 | A | エリア ID・サブネット・Hello/Dead タイマー・認証・スタブフラグなどの一致が Full 状態への到達に必要。Router ID は一致条件ではなく一意性が必要 |
| Q11 | B | DR はインターフェースの OSPF プライオリティ（既定 1）が最大のルータ、同値の場合は Router ID が最大のルータが選ばれる |
| Q12 | C | OSPF のコストは「参照帯域幅（既定 10^8）÷ インターフェース帯域幅」で計算される |
| Q13 | D | Router ID は router-id コマンドによる明示指定が最優先、次に最大のループバック IP、最後に最大の物理インターフェース IP の順で決まる |
| Q14 | A | ExStart／Exchange での停滞は、DBD 交換が完了できない MTU 不一致が典型的な原因 |
| Q15 | B | passive-interface は Hello の送信（ネイバー形成）のみを止め、そのインターフェースが属するネットワークの広告自体は継続する |
| Q16 | C | GLBP は AVG が複数の AVF に仮想 MAC を割り当てて負荷を分散させ、**単一のグループ内で**複数台が同時に転送できる唯一の FHRP。なお HSRP・VRRP でも、グループを複数作って VLAN ごとに Active / Master を分ければ機器単位の負荷分散は可能で、「1 グループ内で同時転送できる」点が GLBP 固有である。VRRP は業界標準（RFC 5798）、HSRP は Cisco 独自 |
| Q17 | D | Active ルータが仮想 MAC アドレスで ARP 要求に応答する。Standby ルータは応答しない |
| Q18 | A | inside global は内部端末が外部から見えるときの変換後（公開）アドレスを指す |
| Q19 | B | PAT はグローバル IP に加え L4 のポート番号を変換テーブルに記録し、戻りパケットの宛先ポートから内部ホストを一意に特定する |
| Q20 | C | `ip nat inside source static` は 1 対 1 固定のマッピングを行う静的 NAT のコマンドで、サーバの常時公開に適する |
| Q21 | D | ポート番号付きで Pro 列にプロトコルが表示されるのは PAT（NAT オーバーロード）の特徴。静的 NAT はポート番号を伴わない |
| Q22 | B | L2 の CoS は 802.1Q タグ内 3 ビット、L3 の DSCP は IP ヘッダの ToS フィールド内 6 ビット |
| Q23 | B | 正引きは IPv4 が A レコード、IPv6 が AAAA レコード。PTR は逆引き、CNAME は別名の対応付けに使う |
| Q24 | B | ポリシングは超過分をバッファせず即時に破棄または再マークするため遅延は増えないがパケットロスが出る。シェーピングは超過分をバッファに貯めて送出を遅延させ、レートを平滑化する |
| Q25 | 例 | 静的設定なら「グローバルで `ipv6 unicast-routing` を有効化 → インターフェースで `ipv6 address <アドレス>/64` → `no shutdown`」の流れ、SLAAC なら「ホストが RS をマルチキャスト送信 → ルータが RA でプレフィックスを返す → ホストが受け取ったプレフィックスと自身で生成したインターフェース ID を組み合わせてアドレスを構成する」という NDP を用いた一連の動作に触れていれば正解 |

**採点基準**: 1 問 4 点（25 問 × 4 点 = 100 点満点）、70 点未満は再テスト対象とする。
Q25 は記述式のため、選んだ側の主要な手順・動作に触れていれば部分点を含め
満点として扱う。
