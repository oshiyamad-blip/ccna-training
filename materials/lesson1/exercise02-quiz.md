## 設問

**Q1.** TCP と UDP の比較として正しいものはどれか。

- A. UDP は確認応答と再送によって信頼性を確保する
- B. TCP はヘッダサイズが UDP より小さい
- C. TCP はコネクションレス型のプロトコルである
- D. UDP はヘッダが小さく低遅延だが信頼性を保証しない

**Q2.** TCP の 3 ウェイハンドシェイクの正しい順序はどれか。

- A. SYN → ACK → SYN/ACK
- B. SYN → SYN/ACK → ACK
- C. ACK → SYN → SYN/ACK
- D. SYN/ACK → SYN → ACK

**Q3.** HTTPS が使用するポート番号とトランスポート層プロトコルの組み合わせ
として正しいものはどれか。

- A. 80 番・TCP
- B. 443 番・UDP
- C. 443 番・TCP
- D. 8080 番・TCP

**Q4.** 動的（エフェメラル）ポートの範囲はどれか。

- A. 0〜1023
- B. 49152〜65535
- C. 1024〜49151
- D. 1〜65535

**Q5.** スイッチがフレームを受信したとき、MAC アドレステーブルへ登録する
情報はどれか。

- A. 宛先 MAC アドレスと送信元ポート
- B. 送信元 IP アドレスと受信ポート
- C. 宛先 IP アドレスと送信元ポート
- D. 送信元 MAC アドレスと受信ポート

**Q6.** 宛先 MAC アドレスが MAC アドレステーブルに存在しない
（unknown unicast）場合、スイッチの動作として正しいものはどれか。

- A. 受信ポート以外の全ポートへフラッディングする
- B. フレームを破棄する
- C. 送信元へエラーを返す
- D. ARP で問い合わせてから転送する

**Q7.** ARP Reply の送信方式はどれか。

- A. ブロードキャスト
- B. マルチキャスト
- C. エニーキャスト
- D. ユニキャスト

**Q8.** デュプレックスミスマッチが発生する典型的な原因はどれか。

- A. 片方が auto、もう片方が固定（full/half）に設定されている
- B. 両端とも auto に設定している
- C. 両端とも同じ固定値に設定している
- D. ケーブル長が 100m を超えている

**Q9.** 802.3at（PoE+）の最大給電電力（PSE 側）はどれか。

- A. 15.4W
- B. 90W
- C. 30W
- D. 60W

**Q10.**（記述）あるスイッチに新規 PC を接続して他ホストへ初めて通信するとき、
スイッチの MAC アドレステーブルと ARP がどのように動作してフレームが宛先に
届くまでの流れを、フラッディングと学習の観点を含めて説明せよ。

## 解答・解説（次の Exercise の開始時に公開・講師用）

| 問 | 解答 | 解説 |
|---|---|---|
| Q1 | D | UDP はヘッダが 8 バイトと小さく低遅延だが、確認応答・再送を行わないため信頼性は保証しない |
| Q2 | B | TCP のセッション確立は SYN → SYN/ACK → ACK の順で行われる |
| Q3 | C | HTTPS は TCP 443 番を使用する。HTTP は TCP 80 番 |
| Q4 | B | 動的 / エフェメラルポートは 49152〜65535。クライアントが接続のたびに送信元ポートとして使用する |
| Q5 | D | スイッチは受信フレームの送信元 MAC アドレスと受信ポートを対応づけて MAC アドレステーブルに登録する |
| Q6 | A | 宛先が不明（unknown unicast）な場合、スイッチは受信ポート以外の全ポートへフラッディングする |
| Q7 | D | ARP Request はブロードキャストで送信されるが、それに対する ARP Reply は要求元へのユニキャストで返信される |
| Q8 | A | 片方が auto、もう片方が固定という組み合わせではオートネゴシエーションが成立せず、デュプレックスミスマッチが発生する |
| Q9 | C | 802.3af（PoE）= 15.4W、802.3at（PoE+）= 30W、802.3bt（PoE++）= 60〜90W |
| Q10 | 例 | 「新規 PC が最初にフレームを送信すると、宛先 MAC が不明なため unknown unicast としてスイッチは受信ポート以外の全ポートへフラッディングする。同時にスイッチは新規 PC の送信元 MAC アドレスと受信ポートを MAC アドレステーブルに学習する。宛先が同一 LAN 内の別ホストで IP アドレスしか分かっていない場合は、先に ARP Request をブロードキャストし、該当ホストが ARP Reply をユニキャストで返すことで MAC アドレスを解決する。以降はスイッチが学習した MAC アドレステーブルをもとに、該当ポートへユニキャストでフレームを転送する」という趣旨で、フラッディング・学習・ARP の 3 点に触れていれば正解 |

**採点**: 1 問 10 点、70 点未満は次の Exercise の冒頭で再テスト。Q10 は
フラッディング・学習・ARP の 3 つの観点のうち主要な論点に触れていれば 10 点。
